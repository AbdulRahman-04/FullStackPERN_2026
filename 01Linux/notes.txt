# Linux Notes

## What is Linux?

Linux is an open-source operating system, similar to Windows and macOS. It is based on Unix-like architecture and is widely used for servers, development, and backend systems.

Linux is free and highly customizable. It is known for being stable, secure, and lightweight.

Linux comes in different distributions, commonly called **distros**, such as Ubuntu, Debian, and Fedora. These distros use the Linux kernel but can have different tools, package managers, and desktop environments.

## Basic Commands

| Command  | Description                                                 |
| -------- | ----------------------------------------------------------- |
| `pwd`    | Shows the current working directory                         |
| `ls`     | Lists files and directories                                 |
| `cd`     | Changes the current directory                               |
| `mkdir`  | Creates a new directory                                     |
| `rmdir`  | Removes an empty directory                                  |
| `rm`     | Removes files or directories (`-r` is used for directories) |
| `cp`     | Copies files or directories                                 |
| `mv`     | Moves or renames files or directories                       |
| `touch`  | Creates an empty file or updates its timestamp              |
| `find`   | Searches for files and directories                          |
| `locate` | Searches for files using a pre-built database               |
| `stat`   | Shows detailed information about a file                     |
| `tree`   | Shows files and directories in a tree structure             |

## File & Text Processing

| Command         | Description                                               |
| --------------- | --------------------------------------------------------- |
| `cat`           | Displays file contents                                    |
| `tac`           | Displays file contents in reverse order                   |
| `more` / `less` | Views file contents page by page                          |
| `head`          | Shows the first 10 lines of a file by default             |
| `tail`          | Shows the last 10 lines of a file by default              |
| `grep`          | Searches for a specific text or pattern                   |
| `sed`           | Searches and modifies text                                |
| `awk`           | Extracts and processes text, especially column-based data |
| `cut`           | Extracts specific parts of a line                         |
| `sort`          | Sorts lines alphabetically or numerically                 |
| `uniq`          | Removes or counts duplicate lines                         |
| `diff`          | Compares two files line by line                           |
| `cmp`           | Compares two files byte by byte                           |

## File Permissions & Ownership

| Command | Description                                                          |
| ------- | -------------------------------------------------------------------- |
| `chmod` | Changes file or directory permissions                                |
| `chown` | Changes the owner of a file or directory                             |
| `chgrp` | Changes the group of a file or directory                             |
| `umask` | Controls default permissions for newly created files and directories |

## Process Management

| Command  | Description                                                    |
| -------- | -------------------------------------------------------------- |
| `ps`     | Shows currently running processes                              |
| `top`    | Shows running processes and system resource usage in real time |
| `htop`   | Interactive alternative to `top`                               |
| `kill`   | Terminates a process using its PID                             |
| `pkill`  | Terminates processes by name                                   |
| `nice`   | Starts a process with a specific priority                      |
| `renice` | Changes the priority of a running process                      |
| `jobs`   | Shows background and suspended jobs in the current terminal    |
| `bg`     | Resumes a suspended job in the background                      |
| `fg`     | Brings a background job to the foreground                      |

## Networking & System Information

| Command             | Description                                                      |
| ------------------- | ---------------------------------------------------------------- |
| `ifconfig` / `ip a` | Shows network interface information                              |
| `ping`              | Checks connectivity to another host                              |
| `netstat`           | Shows network connections (deprecated on many systems; use `ss`) |
| `ss`                | Shows active network connections and sockets                     |
| `wget`              | Downloads files from the internet                                |
| `curl`              | Sends and receives data from URLs; commonly used for API testing |
| `df`                | Shows disk space usage                                           |
| `du`                | Shows the space used by files and directories                    |
| `uptime`            | Shows how long the system has been running                       |
| `uname -a`          | Shows system and kernel information                              |
